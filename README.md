# Sales-Data-Analysis-Dashboard-Power-BI
This project focuses on analyzing sales data using Microsoft Power BI to identify sales trends, product performance, customer purchasing patterns, and order distribution.
The dashboard provides interactive visualizations and key performance indicators (KPIs) to help businesses monitor sales performance and make data-driven decisions.

# Sales Dataset
- <a href="https://github.com/Arizdli/Sales-Data-Analysis-Dashboard-Power-BI/blob/main/Sales_Data.xlsx">Sales_Data</a>

## Project Objectives

- Analyze overall sales revenue and quantity.
- Identify top-performing product categories.
- Track sales performance by year and quarter.
- Analyze order status and payment methods.
- Monitor monthly product category trends.
- Provide interactive filtering for better analysis.
